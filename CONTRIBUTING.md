# Contributing

Thank you for helping improve the Notary Geek public knowledge corpus.

This project is for public-safe, source-backed notary, apostille, identity, routing, and source-quality material.

## Good Contributions

Useful contributions include:

- official state notary-law links;
- official handbook or agency page updates;
- stale-link reports;
- source-backed corrections;
- better route-first examples;
- unclear wording reports;
- missing public source suggestions;
- examples where a platform, trainer, directory, or private standard is being treated like law.

## What To Include

When possible, include:

- the jurisdiction or topic;
- the exact official source URL;
- the date you checked it;
- what is wrong, missing, stale, or unclear;
- the safer wording or source-quality distinction you think should be added.

## Public Boundary

Follow [the public publication policy](docs/publication-policy.md) for contributions and PR discussions. It excludes internal-only work references as well as private data, and preserves supported public corrections. Run the publication checker before submitting.

## Tone

This corpus is meant to help people start from better sources.

Source-backed criticism is welcome. Personal attacks, unsupported claims, and private accusations are not useful here.
