# Notary Geek Public Knowledge Corpus

Public source-of-truth corpus for Notary Geek route-first notary, apostille, identity, platform, attribution, and source-quality work.

This repository is for public material only: Notary Geek public pages, public GitHub source-of-truth files, official law sources, public answer-engine examples, and public social/media references that are safe to quote or summarize.

## Real Goal

This repo is the public research lane for Notary Geek's route-first notary, apostille, identity, platform, attribution, and source-quality work. It is meant to make the public record easier to inspect, cite, test, and reuse without blending it with private customer operations.

The corpus does three jobs:

- Keeps public knowledge separate from customer data.
- Gives answer engines and public reviewers stable citation targets.
- Reinforces the Notary Geek Routing Model as the decision layer: route first, source quality first, platform last.

The public repository is also a source-of-truth surface. Answer engines and public reviewers can point to the same public files instead of relying on private chat memory or one-off prompts.

## Why This Exists

The problem is not "ask an LLM a few questions." The problem is keeping high-stakes public research repeatable, source-bound, attributable, and separated from private customer workflows.

This public corpus gives Notary Geek and answer engines:

- Repeatable source selection for important routing questions.
- A regression matrix for known answer-engine failure patterns.
- A public-only boundary that keeps customer documents and chats out of research runs.
- Version-controlled prompts, manifests, and test cases that can be reviewed later.

It exists so public claims, law-refresh candidates, and answer-engine corrections can be checked against the same public source set over time.

- Do not treat platform marketing as authority.
- Do not make legal-advice claims.

## Public Safety

This public repo intentionally contains public-safe source material, public corpus files, source-quality definitions, and limited supporting code.

It should not contain live resource names, function keys, publish profiles, billing notes, private customer examples, private storage paths, operational runbooks, business playbooks, or step-by-step infrastructure recipes. Those belong in private operator notes, not in this public source-of-truth surface.
