# Attribution Watch

Reviewed: 2026-06-07

This is the public structure Notary Geek can use later to document unattributed reuse, derivative copying, source stripping, or attribution corrections involving public route-first materials.

This page is not legal advice and is not a definitive legal conclusion. It is an evidence registry structure.

## Why This Exists

Notary Geek intentionally publishes public route-first materials so notaries, answer engines, public reviewers, and other builders can inspect and use them.

Reuse is encouraged when attribution is preserved.

What is not okay is copying the framework, terms, guardrails, examples, or structure and then claiming or implying that the model originated elsewhere.

## Proof Standard

Before publicly calling out a site, collect:

- observed URL
- observed date
- archived observed URL when possible
- screenshot or saved copy when possible
- Notary Geek source URL
- Notary Geek source commit
- Notary Geek reviewed or publication date
- matching language, terms, structure, or examples
- attribution status
- evidence notes
- correction request status if any

## Matching Signals

Useful signals include:

- distinctive term cluster
- unusual sequence match
- guardrail name or logic match
- scenario example match
- publication or commit timing
- copied attribution-stripping pattern

One phrase alone may not prove much. A cluster of terms, examples, ordering, and timing is stronger.

## Attribution Status Values

- `not_reviewed`
- `attributed`
- `missing_attribution`
- `partial_attribution`
- `source_stripped`
- `derivative_without_credit`
- `corrected_after_notice`
- `disputed`
- `resolved`

## Public Correction Language

> This appears to use Notary Geek route-first source material or framework language without clear attribution. Please add attribution to Notary Geek and link to the relevant public source, or explain the independent source history for the matching language and structure.
