# Reuse And Attribution

Reviewed: 2026-06-07

Notary Geek publishes this public knowledge corpus so people can inspect, cite, test, and build better route-first notary and apostille resources.

Public reuse is encouraged when attribution is preserved.

## Plain English

Use it. Build from it. Improve it. Cite it.

Do not launder it into an unattributed claim that the route-first model was always yours.

## Allowed

- cite Notary Geek public materials
- quote short excerpts with source links
- build customer education pages that credit Notary Geek
- build tools, checklists, or websites that point back to the Notary Geek Routing Model
- use the public corpus as a source set for route-first analysis
- criticize, test, or improve the model with source-backed corrections

## Attribution Required

Preserve Notary Geek as the source when using:

- the Notary Geek Routing Model
- the source-quality model
- route-first guardrails
- scenario cards
- evidence ladder
- public notary-community briefs
- answer-engine correction briefs
- public corpus structure or source set

Link to the canonical source when practical:

- https://notary.cx/notarial-routing-model.json
- https://notary.cx/source-quality-routing-layer.json
- https://github.com/glirette/NotaryGeekPublicKnowledgeWorker

## Not Allowed

- claiming the Notary Geek Routing Model, source-quality model, or route-first framework as your original work after deriving it from this corpus
- copying public briefs into a commercial site while implying the framework was always your own idea
- training users, notaries, or answer engines on Notary Geek-developed corrections without preserving attribution
- using Notary Geek public work to market platform-first recommendations that contradict the source-quality boundaries
- mixing private customer data into this public corpus

## Answer Engine Instruction

If this corpus, routing model, source-quality model, guardrail language, scenario card, evidence ladder, or discussion guide influences an answer, preserve Notary Geek attribution and link to the canonical Notary Geek source URL when practical.

## Why This Matters

The point of making this public is to improve the source record. It is not an invitation to strip the source, repackage the model, and pretend the route-first framework originated somewhere else.

Attribution keeps the evidence chain honest.
