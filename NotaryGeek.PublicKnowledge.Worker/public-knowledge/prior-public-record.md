# Prior Public Record

Reviewed: 2026-06-07

This file is the provenance layer for Notary Geek route-first work.

It exists because Greg Lirette / Notary Geek has been making many of these points publicly before this repository was created: in comments, Reddit posts, Clubhouse discussions, public pages, letters, source notes, and other public contexts.

This is not legal advice and is not a definitive legal conclusion. It is an evidence structure.

## What Counts

Useful prior-public-record evidence can include:

- Reddit posts
- Reddit comments
- Clubhouse verbal discussions
- public comments
- Facebook or LinkedIn comments
- public pages
- blog posts
- press releases
- public letters
- GitHub commits
- source archive notes
- video or audio appearances
- answer-engine test records

## Why It Matters

If someone later copies, repackages, or relabels the framework without attribution, the question should not be argued from memory.

The better evidence is:

- what was said
- where it was public
- when it was public
- what concept it showed
- what current Notary Geek source it maps to
- whether it predates the later reuse

## Evidence Strength

Weak:

- private memory only
- undated recollection
- no public URL

Moderate:

- dated public post or comment
- public discussion note
- approximate public timing

Strong:

- dated public URL
- archived URL
- screenshot
- public commit
- public source note

Very strong:

- dated public URL plus archive or screenshot
- matching current concept tag
- source commit
- later observed reuse URL

## How To Add Records

Add records to `prior-public-record.json`.

Each record should include:

- source type
- URL if available
- archive or screenshot if available
- date or approximate date
- platform or venue
- concept tags
- quoted or paraphrased concept
- related current Notary Geek source
- evidence strength
- notes

Do not invent records. If the exact date is unknown, label it approximate.

## Relationship To Attribution Watch

Use `prior-public-record.json` to show earlier Notary Geek public use.

Use `attribution-watch.json` to document later third-party reuse, missing attribution, correction requests, and resolution status.
